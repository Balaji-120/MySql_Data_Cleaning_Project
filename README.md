# MySql_Data_Cleaning_Project

## 📌 Overview:
This project demonstrates data cleaning techniques using **MySQL** to prepare raw data for analysis. It focuses on improving data quality through SQL queries.

## 🛠️ Technologies
- MySQL
- SQL
- MySQL Workbench

## 📋 Key Tasks
- Removed duplicate records
- Handled missing values
- Standardized data formats
- Cleaned inconsistent data
- Improved data quality for analysis

## 🚀 How to Use
1. Clone this repository.
2. Import the dataset into MySQL.
3. Execute the `Data Cleaning.sql` script.
